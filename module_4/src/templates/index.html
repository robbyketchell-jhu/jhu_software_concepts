Pull Data

Pull Data checks Grad Café for newly submitted application results and adds new records to the database. Depending on the amount of new data available, this may take some time. Only one pull runs at a time, and a pull never removes or overwrites usable existing records.

Update Analysis (top right) re-queries PostgreSQL and redraws this page with the latest numbers. It does not start a scrape. While a pull is running it reports that new data is being retrieved and leaves the pull alone.
