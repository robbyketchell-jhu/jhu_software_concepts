Module 1: Personal Website in Flask

A multi-page personal website built with Flask and Jinja templates. Pages share a single base.html layout and a navigation menu on the top right The nav is defined once and the current page is highlighted automatically by matching each link against the active Flask endpoint.

Routes are organized in a Flask Blueprint, which keeps the URL definitions in one module and makes the endpoint names static/constant if the paths change later. Styling is in a single styles.css file.

Built with: Python, Flask, Jinja2, HTML, CSS
